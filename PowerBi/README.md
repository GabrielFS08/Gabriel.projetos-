# Dashboard de vendas

Este projeto é um dashboard interativo de vendas feito para centralizar, analisar e visualizar os principais indicadores de desempenho comercial. Ele permite acompanhar métricas em tempo real, como faturamento, volume de vendas com base no arquivo "Vendas.xlsx". Com relatórios dinâmicos e gráficos intuitivos, facilitando a identificação de tendências e gargalos no funil de vendas; Ajudando na tomada de decisões estratégicas baseadas em dados para otimizar os resultados do negócio.

É apresentado nesse dashboard:

- Vendas por marca
- Faturamento
- Produto mais vendido
- Faturamento e Qtd. Vendida por Ano e Mês
- Faturamento por continente
