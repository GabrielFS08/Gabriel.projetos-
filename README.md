# Meus Projetos para a área de dados 🎲

## Pra que foi feito esse repositório?
Fiz esse repositório para documentar todos os meus projetos envolvendo a área de dados, é voltado tanto para Análise de dados quanto para Engenharia de Dados. Eu especifíco melhor o objetivo de cada projeto no arquivo "README.md" dentro de cada pasta do projeto.

## Oque precisa para executar os projetos?
Será necessária uma IDE como VScode, Pycharm, entre outras; E o Python têm que estar instalado na máquina. Dependendo do projeto será necessárias ferramentas além do VScode, como o PowerBI. Para as bibliotecas usadas fiz um arquivo "requirements.txt" que inclui todas as bibliotecas que eu usei para fazer cada projeto. Após criar um ambiente virtual e ativá-lo use:
```Python
pip install -r requirements.txt
```
