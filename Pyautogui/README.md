# Automação de tarefas e bots

Este projeto de automação de tarefas utiliza Python para interagir diretamente com o sistema de uma empresa (um ambiente simulado pela Hashtag Treinamentos). Por meio do controle automatizado de mouse e teclado, o script realiza o login na plataforma e o cadastro em massa de todos os produtos de forma rápida, eliminando o trabalho manual e repetitivo.

Os passo são:

- Importar a base de dados dos produtos
- Abrir o sistema em um navegador escolhido
- Colocar um tempo de espera entre os comandos
- Colocar um tempo de espera para o site carregar
- Fazer o login
- Registrar os produtos
