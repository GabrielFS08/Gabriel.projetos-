# Análise de dados de um banco com Pandas e Plotly

Este é um projeto de análise de dados focado em identificar os principais motivos de cancelamento em um banco com mais de 50 mil clientes. Para o desenvolvimento, utilizei a biblioteca Pandas para o tratamento e limpeza da base de dados, e o Plotly para gerar gráficos interativos e extrair insights estratégicos.

os passos são:

- Importar a base de dados
- Visualizar as informações dela
- Identificar erros e tratá-los
- Fazer uma análise inicial para entender quantos clientes cancelaram
- Depois uma análise detalhada para saber a causa do cancelamento dos clientes
